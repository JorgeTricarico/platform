## Que salio bien
- **TDD estricto**: todos los tests escritos antes de implementar, rojo confirmado, luego verde
- **Velocidad**: Z7 fue ~5 min (import + try/catch + 4 tests), muy quirurgico
- **Componentes bien aislados**: NotificationBell y PhotoGallery son 100% independientes, testeables sin el resto de la app
- **Migracion Zenco chat a startChat**: cambio minimo en backend (5 lineas) habilito memoria completa
- **Patron consistente**: ambos bots ahora usan exactamente el mismo patron (startChat + history)

## Que salio mal
- **Sub-agentes siguen con problemas**: el contexto MCP (PostHog ~150 tools + Slack) hace que los sub-agentes reciban prompts muy largos. Funciona delegando a agentes de tipo Explore/sonnet pero el overhead es alto
- **Directorio incorrecto al correr tests**: correr vitest desde root en vez de backend/ dio 126 failures falsos — perdida de tiempo diagnosticando
- **Dashboard.test.tsx preexistente roto**: 3 tests fallan por cambios previos no relacionados, ensucia el output

## Lecciones aprendidas
- Siempre correr tests desde el directorio correcto (`cd backend && npx vitest run`)
- Para features que son solo "agregar al if existente" (Z7), el approach mas eficiente es: leer el punto de insercion → escribir tests → implementar → verificar
- Los ChatDemo eran stateless por diseño original — enviar history es trivial en el frontend pero requiere que el backend lo soporte
- NotificationBell usa clientId="all" como workaround — en produccion deberia filtrar por usuario logueado
