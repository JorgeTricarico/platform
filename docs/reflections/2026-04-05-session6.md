## Lecciones aprendidas
- Para features frontend-only (PDF, UI toggles), TDD con vitest + jsdom funciona perfecto — no necesita backend
- `jspdf-autotable` maneja paginacion automaticamente, no hay que implementarla manual
- Cuando agregas estado compartido via Context, extraer el contenido en un componente interno (`AppContent`) permite usar hooks dentro del Provider
- El keyframe `@keyframes pulse` debe estar en CSS global si se usa en multiples componentes (sidebar + player)
