## Que salio bien

## Que salio mal
- **Bug garments POST**: el endpoint existia hace sesiones pero nunca se testeo. Fallo en produccion
- **Migracion DB no ejecutada**: se agregaron modelos a Prisma pero no se corrio db push. Todo compila pero falla en runtime
- **Error handling opaco**: los catch solo devolvian "Error al crear orden" sin loguear el error real
- **Demasiado scope sin tests**: se implementaron 6+ features nuevas sin tests primero

## Lecciones aprendidas
- TDD no es opcional: cada endpoint necesita test ANTES de ser "terminado"
- Siempre loguear el error real en los catch, no solo devolver un mensaje generico
- Despues de modificar schema.prisma, verificar que db push se ejecuto (no solo prisma generate)
- Para proyectos chicos con contexto conocido, el orquestador puede leer directamente sin delegar todo

## Ideas nuevas surgidas
- Pre-commit hook que corra vitest (evita pushear sin tests)
- Migration detector: comparar schema.prisma vs DB real y alertar si hay drift
- Zod validation en todos los endpoints (validar antes de prisma)
- CI con GitHub Actions (tsc + vitest en cada push)
