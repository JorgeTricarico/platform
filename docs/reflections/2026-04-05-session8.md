## Problemas Encontrados

1. **Free tier Gemini agotado** — gemini-2.0-flash y flash-lite ambos con quota 0. Tests E2E necesitan plan pago o esperar reset diario.
2. **WSL network** — ENETUNREACH al intentar conectar a Supabase via pg. Problema conocido, workaround con SQL Editor.
3. **Express v5 types** — `req.params` ahora es `string | string[]`, requiere cast explícito. Afectaba 5 archivos de rutas.

## Decisiones

- Chat history usa `createMany` (2 msgs por request) en lugar de endpoint POST separado — menos latencia, menos complejidad
- sessionId = UUID parcial por día en localStorage — suficiente para MVP, multi-dispositivo via DB
- E2E tests excluidos del vitest.config.ts default — solo se corren explícitamente
- Migration script genera SQL completo (from-empty) con IF NOT EXISTS — idempotente, seguro de re-ejecutar
