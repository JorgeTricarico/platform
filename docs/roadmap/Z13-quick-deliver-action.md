# Z13 — Acción rápida "Marcar entregado"

**Prioridad:** MEDIA UX
**Estado:** Pendiente

## Problema
Cambiar estado a "entregado" requiere abrir modal completo, cambiar dropdown, guardar. Demasiados pasos para la acción más frecuente del día.

## Solución
En las filas con status "listo", mostrar botón "Entregar" que cambia el estado directamente con un click (con confirmación).
