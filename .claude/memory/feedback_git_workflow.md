Pushear directo a main, sin crear ramas feature ni PRs.

**Why:** El usuario trabaja solo en estos proyectos y quiere velocidad, no overhead de branches.
**How to apply:** Siempre commitear y pushear a main directamente. No crear ramas temporales. Limpiar cualquier rama vieja que exista.
