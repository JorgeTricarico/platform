Siempre commitear y pushear directo a main al terminar el trabajo. No preguntar "¿commiteo?".

**Why:** El usuario quiere flujo rápido sin confirmaciones innecesarias.
**How to apply:** Al terminar cada bloque de trabajo, hacer commit + git push automáticamente.
